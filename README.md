# 20-Day Live Arduino Programme: Submission Starter

This is the template repository for students on the **20-Day Live Arduino Programme** from [eARgle Innovation Labs](https://earglelabs.com). Each day you build something, push it here, and submit the link for your instructor to review and approve.

## Start here

Press the green **Use this template** button at the top of this page and choose **Create a new repository**. Name it `arduino-20-days-<yourname>` and keep it public so your instructor can open it.

Do not fork this repository. A template copy gives you a clean history of your own work.

## What to submit each day

Create a folder named `day-01`, `day-02` and so on, and put three things in it.

| File | What goes in it |
| --- | --- |
| `sketch.ino` | The code you wrote that day, with comments explaining what each part does |
| `NOTES.md` | What the task was, what you wired up, what went wrong and how you fixed it |
| `photo.jpg` | A photo of your working circuit on the breadboard |

Then copy the link to that day's folder and paste it into the submission box on [earglelabs.com](https://earglelabs.com).

## Committing your work

```bash
git add day-05
git commit -m "Day 05: ultrasonic distance sensor"
git push
```

If you are using GitHub Desktop or the web interface instead, that is fine too. What matters is that the folder is in your repository before the deadline.

## Rules that make review easy

One folder per day, named exactly `day-01` through `day-20`. Commit on the day you do the work, so the dates line up. Write your own code, and say so in `NOTES.md` when you used help, which is allowed and expected. A day that does not compile still counts if `NOTES.md` explains what you tried.

## Stuck?

Ask in the live session, open an issue on your own repository and tag your instructor, or write to info@eargle.tech.
